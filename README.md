## Как работает
- Сервер: `living_incoming_damage` кладёт удар в очередь, конец тика: тема по типу урона, комбо (уровень не чаще 1 с),
  большой эдит не чаще `big_edit_cooldown`, на `combo_max` «НЕИГРАБЕЛЬНО» и тишина. Пакет `kotost_aura:edit` жертве.
- Куст/кактус + большой эдит: в `level_tick` спавнится хаск без ИИ с именем «Ягода-сигма» в 2,2 блока перед игроком, живёт
  `char_seconds`. Его id жертве (`kotost_aura:char`). Убил его игрок: реванш, +аура, мини-эдит убийце.
- Клиент: 0,5 с вжух и отъезд зума, потом доли по `bpm`. Каждые 2 доли смена кадра: лицо, пустота (чёрный туман), Ягода снизу,
  облёт, небо, «MOGGED» (серый), крупно (последние 2 доли, красный и взрыв). Вид от 3-го лица на время эдита, потом возврат.
- Бит из ванильных звуков: кик (сердце вардена + бочка нотного блока), снейр, хэт, колокол на склейках. Свой трек: `track =`,
  громкость бита под ним `beat_volume` (0: выкл). Вжух за 0,5 с до дропа всегда модовый.

## Музыка эдита (только локально)
- В мод трек не входит (чужая музыка): только локальный ресурспак, например `game/resourcepacks/kotost_aura_music`
  (`assets/kotost_aura/sounds/edit_track.ogg`, `sounds.json`: `edit_track`, stream). Не класть в `kotost_aura_assets`.
- Свой трек: ogg vorbis 44,1 кГц, начало за 0,1 с до дропа, длина `edit_seconds` + 0,3 с затухания, около -14 LUFS.
  Положить как `edit_track.ogg` в такой же ресурспак, включить его, в `config/kotost_aura.txt`: `track = kotost_aura:edit_track`,
  `bpm =` темп трека. Свой id: `<namespace>:<событие>` из `sounds.json` своего пака.
- Трек играет слоем музыки: если тихо, поднять ползунок «Музыка».
- Модель Ягоды: кубы из ванильных текстур (белый бетон, листья, красный бетон), поворачивается к смотрящему, кивает в долю.
  Если стоит спиной: `FACE_SIGN = -1.0` в `edit.rs`.
